# Cubeland 🧱

Cubeland est une réimagination open source d'un environnement de type voxel, entièrement conçue avec l'assistance de Claude. Ce projet explore le potentiel des assistants IA pour architecturer et coder des jeux complexes de A à Z.

## 🚀 À propos du projet
L'objectif de Cubeland est de fournir une base de code propre, modulaire et extensible pour les développeurs souhaitant apprendre à construire des moteurs de jeu en utilisant des outils de pair-programming assistés par IA.

## 🛠️ Fonctionnalités principales
*   **Moteur Voxel** : Génération et rendu d'un monde interactif.
*   **Architecture modulaire** : Facile à étendre pour de nouveaux types de blocs ou de mécaniques.
*   **Documentation technique** : Chaque étape majeure du développement est documentée pour faciliter la compréhension du code.

## 📦 Installation
1. Clonez ce dépôt : `git clone [ton-url-de-repo]`
2. Installez les dépendances : `npm install` (ajuste selon ton langage)
3. Lancez le projet : `npm start`
